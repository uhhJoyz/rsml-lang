# Completion cases for scripts/check_completion.py.
#
# `== name -> label ..` starts a case: the labels rust-analyzer must offer.
# The lines after it are the code, `$0` marking the cursor. Code is the body
# of `ml! { .. }` in a function with these locals:
#
#   xs: Vec<i64>, s: &str, word: String, p: Point, o: Option<String>,
#   n: i64, shape: Shape, ord: std::cmp::Ordering
#
# (and the items of PRELUDE in the script: Point { x, y } with `norm`,
# Shape::{Circle, Rect}, add, twice, geometry::{area, ORIGIN}). Code that
# starts with `rsml!` is an item instead.
